UT4 · Act. 4 — Pedido de Restaurante 
Yeray Musila y Gabriel Sánchez

Este programa es un programa el cual se trata de un pedido de un restaurante. Se empezó por el Articulo.java , Pedido.java y EstadoPedido.java, que es la parte que hizo Yeray, más tarde se hizo el Main y el README que lo hice yo. Hemos utilizado varios métodos como mostrarArticulo y hemos implementado todo en conjunto para que el programa pueda leer la cantidad de pedidos y no vaya hacia detras en el estado del producto, para eso hemos hecho el EstadoPedido.java en el cual asignamos cada uno de los estados de los productos.
